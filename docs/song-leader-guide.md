# Remote Keypad: Song Leader Guide

Use the Remote Keypad to show a song number on the board when **nobody is sitting on the Song Leaders' Bench**: phone patches, viewings, gatherings.

> **Rule:** The Remote Access Switch is **OFF** whenever anyone is on the Song Leaders' Bench. Turn it on only when you'll set the numbers from your phone.

## Connect

1. Turn the **Remote Access Switch ON**. Wait about 30 seconds.
2. Connect your phone to the church's **staff Wi-Fi**. It won't work from the guest Wi-Fi.
3. Open **`http://hymn.local`** in your phone's browser.
   If it doesn't open, use the address written on the box's label instead.

Tip: bookmark it or add it to your home screen.

## Use it

| To… | Do this |
| --- | --- |
| Show a song | Type the number (up to 3 digits) and tap the green **On** button. |
| Blank the board | Tap the red **Off** button. |
| Show the same song again (e.g. after the prayer) | Type the number again and tap **On**. |
| Change to a different song | Tap **Off**, type the new number, tap **On**. |

- The board blanks itself **7 minutes** after you tap On, in case it's forgotten. To show the same number again, just tap **On**.
- Numbers are 1 to 999. **0** isn't a song number.
- Verses aren't shown on the board. Announce them as usual.

## When you're done

Tap **Off**, then turn the **Remote Access Switch OFF**.

## If something's wrong

- **The page won't open:** make sure you're on the staff Wi-Fi (not guest) and the switch is on. Try the address on the label.
- **The page opens but the board doesn't change:** turn the switch off, wait 10 seconds, turn it on, and try again.
